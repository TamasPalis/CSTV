# Counter-Strike Hír és webshop oldal

Nemzetközi Esport Szövetség megbízásából, Egy összekötő weboldal a legmagasabb szintű csapatoknak és versenyeknek. **Hírek, igazolások, Játék Frissítések**

## Elvárások:
- Főoldal, elosztó a csapatoknak (Top 5)
- Versenykalendárium (Pár példa, nem túl komplikált. Bootstrap grid rendszer)
- Minimalista design, átlátható, mégis figyelemfelkeltő színvilág
- **Webshop összekötés a csapatok között**
